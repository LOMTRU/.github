# Ломть LMS

Учитесь Java на практике: выполняйте задания, получайте комментарии преподавателя и возвращайтесь к материалам в одном личном кабинете.

Начните с [шести бесплатных уроков без регистрации](https://lomt.ru/uroki/): от установки JDK и первой программы до классов и объектов. Если нужен учебный план и проверка решений, [посмотрите курсы](https://lomt.ru/kursy/) и [оставьте заявку](https://lomt.ru/zayavka/).
